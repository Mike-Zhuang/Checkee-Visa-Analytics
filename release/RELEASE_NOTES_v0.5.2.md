# Release Notes v0.5.2

发布日期：2026-03-29

## 亮点

- 完成手机竖屏布局专项修复，公共页与管理页在小屏下不再出现“散架”。
- 保持桌面端样式与交互不变，仅在移动端断点生效。
- 新增响应式断点守护测试，防止后续改动破坏移动端适配。

## 前端变更

- 公共页案例表增加列优先级 class：
  - 在 `<=560px` 隐藏次要列（如雇主、地点、完成日期、计算天数、备注）。
  - 在 `<=420px` 进一步隐藏第三级列（如 Entry）。
- 管理页专业归类表增加列优先级 class：
  - 在 `<=560px` 隐藏次要列（自动归类）。
  - 在 `<=420px` 进一步隐藏第三级列（来源）。
- 小屏密度优化：
  - 表格最小宽度按断点收敛，减少横向挤压。
  - 管理页操作按钮在小屏改为纵向堆叠，提升可点击性。
  - 分页与筛选区在小屏下进一步压缩间距。
- 表格滚动体验优化：
  - 增加 `-webkit-overflow-scrolling: touch` 与 `overscroll-behavior: contain`。

## 测试与验证

- 新增测试：`frontend/src/test/responsive-breakpoints.test.js`
  - 守护 `560px` 与 `420px` 的关键断点规则。
  - 守护移动端列隐藏策略与表格最小宽度约束。
- 扩展测试：
  - `case-table.test.tsx` 增加移动端列 class 挂点断言。
  - `admin-page.test.tsx` 增加管理页列 class 挂点断言。
- 本地校验结果：
  - `pnpm run test`：24/24 通过。
  - `pnpm run build`：通过。
- 手工点检：
  - 已完成 375 / 768 / 1280 三档截图巡检（公共页与管理页登录前主模块）。
